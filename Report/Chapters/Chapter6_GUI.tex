\section{Course Session Organiser class}

\paragraph{The need for this class arose when we were working on the GUI. We noticed that when we ran the application and went straight into the HOD view, the HOD course summary would not show all the course. We discovered that the application only had one hardcoded course. This caused the application to forget any newly created course once the application was closed.

The solution was to create the class called \texttt{CourseSessionOrganiser.java} which scans the storage folder named data for files with the \texttt{*_marks.csv} as part of the name. Once found it rebuilds that course proflie in the application. Also whenever a user switches a course, this class ensures the correct student lists, marks, and file savers are loaded instantly, keeping everything safe and isolated.}
