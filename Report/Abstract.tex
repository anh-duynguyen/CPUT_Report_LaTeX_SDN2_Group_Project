\section*{Abstract}
\addcontentsline{toc}{section}{Abstract}

This document describes the design of the Marks Administration System, a Java desktop application that lets lecturers at the Cape Peninsula University of Technology capture, import and manage student marks, and lets a Head of Department inspect results without being able to change them. The problem addressed is the error-prone manual handling of weighted assessment marks, where wrong totals and missing entries are easy to miss. The report presents the layered class design with a UML class diagram, the main design decisions and their trade-offs, the data structures and algorithms used for mark calculation, CSV persistence and class analytics, and the advanced features delivered: a Swing graphical interface, multi-course management, header-driven CSV import and role-based access. The testing strategy, with normal and edge-case evidence, is described together with the defects it exposed. The report closes with reflections on graduate attributes GA2 and GA7 and an account of how the eight-member team collaborated.

\vspace{4mm}
\textbf{Keywords:} object-oriented design, Java, Swing, CSV persistence, marks administration, software testing
